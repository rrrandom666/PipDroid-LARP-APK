# ☢ VAULT-TEC INDUSTRIES (ANDROID DIVISION) ☢  
## PIPDROID PERSONAL INFORMATION PROCESSOR

**Congratulations, Citizen!**

You are now the proud operator of the **PipDroid Personal Information Processor**, a modern Android-compatible recreation of the legendary wrist-mounted device featured in Fallout 3 and Fallout: New Vegas.

Engineered for cosplay operatives, wasteland reenactors, and Vault-Tec enthusiasts, PipDroid delivers that authentic retro-futuristic interface directly to your Android device.

> ⚠ NOTICE: PipDroid is a fan-made cosplay interface project and is not affiliated with or endorsed by Bethesda or any official rights holders.

---

# 📟 DEVICE SPECIFICATIONS

**Vault-Tec Certified Android Compatibility Matrix**

- Minimum Android SDK: 18  
- Target Android SDK: 34  
- Supported Android Versions: 4.3 (Jelly Bean) → Android 14  
- Designed for legacy hardware reclamation & embedded prop installations  

Optimized for:
- Repurposed Android devices
- 3D-printed Pip-Boy housings
- Offline wasteland deployment

# 🟢 STANDARD OPERATING MODULES

## STAT MODULE
- Simulated HP / AP / RAD readouts
- Mock S.P.E.C.I.A.L.-style statistics display
- Power Core battery reinterpretation

## INV MODULE
- Inventory simulation interface
- Categorized item listings
- Scrollable retro terminal UI

## DATA MODULE
- Quest-style informational panels
- Status logs and placeholder mission tracking

## MAP MODULE
- Local map placeholder display
- Wasteland and Mohave location recordings

## RADIO MODULE
- Optional audio playback functionality
- Classic monochrome tuning interface

Then install the PipDroid package manually.
