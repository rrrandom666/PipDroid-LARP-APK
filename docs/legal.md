# Legal standing of the fork

Two separate risks. Neither is resolved.

## 1. Permission from the PipDroid author

The app is a fork of **PipDroid** (https://github.com/Malto4/PipDroid-APK, by Malto4).

The author was contacted (Reddit and a GitHub issue) asking permission to fork for a non-commercial
LARP project. There has been no reply for over two weeks. A follow-up notice was sent saying
development had started locally, without publishing or distributing anything, while waiting.

The repository has no LICENSE file — only a line in the README about non-commercial fan use, which
mentions "Wasteland reenactments" explicitly, exactly this case.

**Do not publish or hand the APK to players until the author answers explicitly.** Installation is by
manual `adb` onto the developer's own device only.

## 2. Visual distance from Bethesda's official app

Bethesda's `com.bethsoft.falloutcompanionapp` is sometimes used as a reference for screen structure
and logic (see the roadmap: the PipBoy 2000/3000 wizard, the new header). That is fine, but it does
not mean copying it literally.

Decorative details — specific icons, the bracket decorations on the active tab, the font and layout —
are not to be carried over one to one. This is a risk independent of the author's permission above:
the non-commercial fan status of the fork must not blur into a visually-too-close clone of another
rightsholder's product.
