# Smoke-чеклист прогона на устройстве

Ручной прогон после каждой волны рефакторинга. Порядок не случайный: сначала то, что
ломается молча (сохранёнки, динамические ресурсы), потом то, что видно сразу.

Автоматическая сверка (`./dev-tools/refactor_snapshot.sh diff baseline after`) закрывает
байткод и ресурсы, но слепа к порядку вызовов в `onCreate` и к динамическим именам —
их закрывает этот список.

## A. Сохранёнки и динамические ресурсы (ломается молча)

- [ ] Имя игрока, регион, год, формат даты после перезапуска приложения на месте
- [ ] Цвет темы после перезапуска тот же (`playerUIColour`)
- [ ] Экран выбора режима открылся на старте — режим спрашивается каждый запуск сознательно,
      на диск не сохраняется (переживает только убийство процесса, через savedInstanceState)
- [ ] STATS → Perks: список отфильтрованных перков тот же, что был (`selectedSTATSPerksArray`)
- [ ] STATS → Perks: **имя и описание перка по-русски**, не английские (резолв `getIdentifier`)
- [ ] STATS → Perks: иконка перка отображается
- [ ] DATA → Misc: отмеченные записи на месте (`selectedDATAMiscArray`)
- [ ] ITEMS → Гейгер: накопленная доза пережила перезапуск (`geigerDose`)
- [ ] ITEMS → Часы → Мелодия: выбранная мелодия сохранилась (`selectedRingtoneIndex`)
- [ ] DATA → Радио: последняя частота восстановилась (`radioLastFrequency`)
- [ ] Настройки: язык, фоновый звук, полноэкранный режим сохранились
- [ ] Bluetooth: MAC и три UUID на месте, коннект поднимается

## B. Анимации включения и выключения

- [ ] POWER: загрузка идёт полностью — кодовая стена, терминал, шапка PIP-OS
- [ ] Число звёздочек в шапке PIP-OS подогнано под ширину экрана
- [ ] Звук набора текста и звук тумблера играют, обрываются корректно при быстром повторе
- [ ] Выключение: затухание в терминал, шапка, звук
- [ ] Глитч-эффект работает и не остаётся навсегда

## C. Навигация энкодером (главный риск волны 3)

По каждой ветке: прокрутка вверх/вниз, вход, выход через Back, прицел-уголки видны и стоят
на правильном элементе, тик играет один раз на шаг.

- [ ] STATS: Status / SPECIAL / Skills / Perks
- [ ] STATS → Status: фигура, части тела, Stop, Revive
- [ ] ITEMS: Карта / Журнал / Часы / Гейгер
- [ ] ITEMS → Карта: зум, центр, панорама, прицел, попап метки, список меток, деталь, маршрут
- [ ] ITEMS → Журнал: список, деталь, редактор (Mic / Cancel / Save)
- [ ] ITEMS → Часы: Будильник, Таймер (настройка и работа), Секундомер, Мелодия
- [ ] ITEMS → Гейгер: Reset, «В меню»
- [ ] DATA: Голодиски / Радио / Misc
- [ ] В режиме Телефон прицелы-уголки **не** показываются нигде
- [ ] Свайп по верхним вкладкам и второй ряд подсвечивают активное

## D. Функции

- [ ] Карта: своё положение, центрирование, постановка метки, имя метки, маршрут, отмена
- [ ] Карта и Журнал: диктовка микрофоном — тап 1 старт, тап 2 стоп, текст дописывается
- [ ] Журнал: создание, правка, удаление записи; дата в списке
- [ ] Часы: будильник срабатывает, оверлей гасится; таймер, пресеты, пауза, сброс; секундомер
- [ ] Status: нанесение и лечение ран, таймер раны, смерть и оживление, звуки damage/stimpack
- [ ] Гейгер: стрелка ходит от `GEIGER:`, Reset обнуляет
- [ ] Радио: включение, частота, визуализатор
- [ ] Голосовые команды: будческое слово, переход по разделам, установка частей тела
- [ ] Звуки UI: тик, кнопка, ошибка, подтверждение — каждый играет и не залипает

## E. Оформление

- [ ] Смена темы в Настройках красит всё **на лету**, без перезапуска
- [ ] Все четыре темы: Green / Amber / White / Blue
- [ ] Смена языка (перезапуск Activity) — интерфейс переведён
- [ ] Масштаб текста применяется
